CAFE STITCH DIGITAL MENU
========================
1. Open index.html locally to preview.
2. To publish on Netlify:
   - Go to https://app.netlify.com/drop
   - Drag this entire ZIP file into the page.
   - Netlify will give you a public link.
3. Send that public link back to ChatGPT and a real QR code can be generated for it.

Notes:
- The supplied cookie photos are matched to Pretzel & Caramel, Kinder, Triple Milk Chocolate,
  Classic Chocolate Chip, Red Velvet, and Amsterdam.
- Oreo and Cornflakes currently use clearly marked branded placeholders because separate real
  photos were not supplied.
